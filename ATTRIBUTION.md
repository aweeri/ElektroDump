# Attribution

ElektroDump is a clean-room reimplementation. It reuses **methods, algorithms,
protocol facts and constants** from published specifications and from the
SatDump/GobDump project, but not its source code or file organization.

## Methodological reference

- **SatDump** and **GobDump** (GPLv3) — the reference implementation whose
  methods informed the demodulation, FEC, CCSDS, xRIT, GGAK, image-composite and
  projection designs. No code is copied verbatim or near-verbatim.

## Protocol specifications

- **CCSDS 131.0-B** — TM Synchronization and Channel Coding (Viterbi, PN
  randomisation, Reed-Solomon).
- **CCSDS 132.0-B** — TM Space Data Link Protocol (AOS / VCDU).
- **CCSDS 133.0-B** — Space Packet Protocol.
- **EUMETSAT LRIT/HRIT Mission Specific Documents** — xRIT file and header
  layouts, CRC-16/CCITT.
- **Roscosmos / Elektro-L GGAK documentation** — GGAK frame layout and SKL
  science records.

## Clean-room policy

Standard tables (CCSDS PN sequence, Viterbi trellis, Reed-Solomon dual-basis
tables, CRC-16 polynomial) are re-derived from the published specifications.
Algorithms, formulas, protocol facts and file-format layouts are not
copyrightable; they are implemented independently here.
